# JLCEDA Contest PCBs

本仓库整理了一组嘉立创 EDA（JLCEDA / EasyEDA）工程文件，主要面向电子设计竞赛、模拟电路练习和常用功能模块复用。仓库只保留截图中选定的 9 个工程文件，没有包含自动备份目录、临时文件或无关工程。

## 工程列表

| 文件 | 类型 | 简要说明 |
|---|---|---|
| `projects/射级跟随器.eprj` | 模拟电路 | 射极跟随器 / 缓冲级相关 PCB 工程。 |
| `projects/差分放大器AD8138.eprj` | 模拟电路 | 基于 AD8138 的差分放大器工程，适合高速/差分信号调理参考。 |
| `projects/TLV3501.eprj` | 比较器电路 | 基于 TLV3501 的高速比较器相关工程。 |
| `projects/ADC前端电路.eprj` | ADC 前端 | 面向 ADC 输入信号调理的前端电路工程。 |
| `projects/同轴电缆.eprj` | 信号连接 | 同轴接口/信号连接相关 PCB 工程。 |
| `projects/OPA847.eprj` | 高速运放 | 基于 OPA847 的高速运算放大器工程。 |
| `projects/同反向放大加减法通板.eprj` | 运放实验板 | 同相、反相、加法、减法等运放基础电路综合实验板。 |
| `projects/OPA695电流反馈运放.eprj` | 电流反馈运放 | 基于 OPA695 的电流反馈运算放大器工程。 |
| `projects/反相加法器.eprj` | 运放电路 | 反相加法器相关 PCB 工程。 |

## 使用方式

1. 打开嘉立创 EDA 专业版或支持 `.eprj` 的嘉立创 EDA 环境。
2. 选择导入/打开工程文件。
3. 从 `projects/` 目录中选择需要查看或复用的 `.eprj` 文件。
4. 根据自己的器件库存、封装、供电范围和竞赛要求重新检查原理图、PCB、BOM 和 DRC/ERC。

## 说明

这些工程文件适合用于学习、竞赛前期方案验证和常用模块复用。实际打板前建议重新执行以下检查：

- 原理图连线与网络名；
- 器件封装与实物型号；
- 电源、电流、散热和安全裕量；
- PCB 设计规则、间距、线宽和铺铜；
- BOM 可采购性与替代料风险。
